# 동글동글 동물 친구들

터치로 같은 동물이나 숫자를 선으로 잇거나 둘러 합치는 1분 30초 협동 게임입니다. 동물원, 수족관, 하늘, 숫자 나라 중 하나를 골라 플레이합니다. 한 화면에서 여러 손가락으로 동시에 그릴 수 있으며 점수는 함께 올립니다.

게임의 화면 흐름, 판정 기준, 점수 밸런스, 제작 순서는 [게임 기획서](docs/GAME_PLAN.md)에 정리했습니다.

## 실행

```sh
pnpm install
pnpm dev
```

프로덕션 빌드와 미리보기:

```sh
pnpm build
pnpm preview
```

HTTPS 또는 localhost에서 서비스 워커가 동작하며, 브라우저의 설치 메뉴에서 PWA로 설치할 수 있습니다.

## 게임 규칙

- 로비의 이미지 카드에서 동물원, 수족관, 하늘 또는 숫자 나라를 고릅니다. 동물 테마는 각각 5종이 등장하고, 숫자 나라는 0~9 중 매 라운드 무작위 5종이 등장합니다.
- 플레이 화면은 가로·세로 모두 화면을 채웁니다. 아이폰 가로 화면에서는 로비와 결과도 스크롤 없이 배치합니다. 점수·시간·최고 기록은 터치를 가리지 않는 투명 HUD로 표시하고, 마지막 5초는 노란 숫자와 흰 외곽선으로 잠깐씩 표시합니다.
- 90초 동안 같은 종류의 동물 또는 숫자 2개 이상을 선으로 잇거나 둘러 손을 떼면 크기가 달라도 하나로 합쳐집니다. 선이 지나가는 대상이 모두 같은 종류라면 열린 선도 성공합니다. 한 번에 여러 개를 함께 합칠 수 있습니다.
- 둘러 그린 영역은 시작과 끝을 자동으로 잇습니다. 같은 종류는 몸의 약 3%만 안에 들어와도 선택됩니다. 다른 종류는 몸의 50% 이상이 들어올 때 영역 합치기를 막습니다.
- 크기는 6단계까지 자랍니다. 높은 단계의 동물을 합쳐 성장시킬수록 점수가 커지며, 여러 마리를 한 번에 합쳐도 성장 보너스를 받습니다. 마지막 단계에서는 크기를 유지하며 계속 합칠 수 있습니다.
- 작은 화면은 유닛 15개, 일반 화면은 20개, 와이드 화면은 30개를 목표로 채웁니다. 시작 배치와 새 유닛은 종류별 무리 없이 화면에 퍼집니다. 유닛마다 이동 속도가 다르고 벽에 닿으면 새 속도가 정해집니다.
- 점수와 테마별 등수는 이 기기의 `localStorage`에 저장됩니다. 온라인 순위에는 별도 서버가 필요합니다.

## 구현 메모

- Three.js 정사영 장면에 동물·숫자 스프라이트와 움직이는 환경 장식을 렌더링합니다. HUD와 결과 화면은 DOM으로 구성했습니다.
- 입력은 포인터 ID마다 독립된 경로를 보관합니다. 터치 기기에서 여러 사람이 동시에 선을 그릴 수 있습니다.
- 수족관과 하늘의 동물은 이동 방향에 맞춰 회전하며 왼쪽으로 갈 때 반전 텍스처를 사용합니다. 숫자는 읽기 쉽게 똑바로 유지합니다.
- 부직포 스타일 동물 PNG 15종은 `public/animals/`에 있습니다. 동물원은 위에서 본 모습, 수족관과 하늘은 옆모습입니다. 숫자 0~9는 같은 질감의 캔버스 이미지로 생성합니다. 제작 기준은 [최종 이미지 기록](docs/FINAL_ART.md)에 있습니다.
- 조용하고 발랄한 배경 멜로디와 짧은 합치기 성공음을 Web Audio로 합성합니다. 합치면 동물이 잠깐 더 커졌다 돌아오는 젤리 동작과 원형 파동·반짝임이 나타납니다. 소리는 기본으로 켜지고 로비 버튼에서 끌 수 있습니다.
- `public/sw.js`가 프로덕션 자산을 캐시합니다. 앱 코드는 빌드할 때 묶입니다.
- 브라우저 파비콘, iOS 홈 화면, 일반·마스커블 PWA 아이콘은 같은 부직포 게임 아트로 제작했습니다.

## GitHub Pages

`main`에 푸시하면 `.github/workflows/deploy.yml`이 pnpm으로 빌드해 GitHub Pages에 게시합니다. 저장소의 **Settings → Pages → Build and deployment**에서 소스를 **GitHub Actions**로 설정해야 합니다. 배포 주소는 `https://clazyzombie.github.io/animal-group/`입니다.
