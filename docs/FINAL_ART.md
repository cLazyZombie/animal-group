# 최종 동물 이미지

스타일 시안 `land-d.png`, `sea-d.png`의 **층을 쌓은 부직포와 손으로 자른 종이 질감**을 사용했다. 게임용 PNG 10종은 [`public/animals/`](../public/animals/)에 있다. 모두 1254×1254 투명 배경이며 동물을 중앙에 배치했다. PWA 아이콘도 같은 스타일의 레서팬더를 별도로 생성했다.

## 제작 프롬프트 기준

- 공통: 어린이 게임용 둥근 실루엣, 따뜻하고 선명한 색, 작은 화면에서도 알아볼 수 있는 종별 특징, 섬세한 섬유 결, 투명 배경, 한 마리의 전신. 글자·바닥·그림자·배경·추가 동물 제외.
- 동물원: `land-d.png`의 질감과 `land-a.png`의 위에서 본 자세를 참조. **정수리·등·네 발·꼬리가 보이는 수직 탑다운 시점**, 머리는 이미지 위쪽. 얼굴 정면이나 측면으로 돌리지 않는다.
- 수족관: `sea-d.png`의 질감 참조. **머리가 오른쪽인 선명한 측면 전신**, 지느러미와 꼬리가 보이고 몸의 입체감은 얕게. 게임에서 왼쪽 이동 시 좌우 반전한다.

| 파일 | 프롬프트에 지정한 식별 특징 |
| --- | --- |
| `toucan.png` | 커다란 주황·노랑 부리, 검은 날개와 몸, 짧은 꼬리 |
| `monkey.png` | 갈색 털, 둥근 귀, 말린 긴 꼬리와 네 손발 |
| `anteater.png` | 길고 가는 주둥이, 등에 V자 무늬, 풍성한 꼬리 |
| `redpanda.png` | 주황 털, 흰 귀와 얼굴 무늬, 줄무늬 꼬리 |
| `crocodile.png` | 길쭉한 초록 몸, 등 비늘, 넓은 주둥이와 꼬리 |
| `ray.png` | 넓은 날개 지느러미, 긴 꼬리, 푸른 윗면 |
| `clownfish.png` | 주황 몸, 흰 세 줄, 검은 지느러미 가장자리 |
| `sunfish.png` | 둥글고 납작한 회청색 몸, 높게 뻗은 등·배지느러미 |
| `whaleshark.png` | 긴 푸른 몸과 흰 점, 큰 꼬리와 지느러미 |
| `seadragon.png` | 노랑 몸, 잎처럼 퍼지는 초록 돌기, 말린 꼬리 |

각 종을 별도 이미지 생성 호출로 제작했다. 로비 카드와 게임판에서 같은 원본을 사용한다.
