# 동글동글 동물 친구들 — 게임 기획서

## 1. 한 줄 기획

여러 사람이 한 화면에서 움직이는 동물과 숫자를 손가락으로 잇거나 둘러 합치고, 90초 동안 함께 최고 점수를 만드는 어린이용 웹 게임.

참고 사진의 핵심인 **밝고 단순한 놀이판, 자유롭게 움직이는 캐릭터, 손으로 그린 영역을 놓는 순간의 변신**을 중심 경험으로 삼는다. 주 사용 환경은 터치가 되는 태블릿과 큰 화면이며, 휴대전화에서도 한 사람이 편하게 플레이할 수 있어야 한다.

## 2. 플레이 흐름

| 순서 | 화면 | 플레이어가 하는 일 | 화면이 알려주는 것 |
| --- | --- | --- | --- |
| 1 | 로비 | 동물원·수족관·하늘·숫자 나라 이미지 카드 중 하나 선택 | 1분 30초 게임, 선 잇기와 둘러 그리기, 여러 명 동시 플레이 가능 |
| 2 | 플레이 | 같은 종류 2개 이상을 선으로 잇거나 둘러 손을 뗌 | 남은 시간, 공동 점수, 최고 점수, 성공·실패 피드백 |
| 3 | 결과 | 점수와 등수 확인 | 이번 점수, 최고 기록, 상위 기록 |
| 4 | 다음 행동 | 다시하기 또는 처음부터 | 같은 테마 재도전 또는 로비로 이동 |

라운드는 카드 선택 즉시 시작한다. 90초가 끝나면 입력을 마감하고 결과를 표시한다. 플레이 중에는 홈 버튼을 두지 않고, 결과 화면에서 같은 테마 재도전 또는 로비 이동을 선택한다.

## 3. 테마와 동물

| 테마 | 카메라·배경 | 동물 5종 | 움직임·환경 연출 |
| --- | --- | --- | --- |
| 동물원 | 위에서 내려다본 초원 | 토코투칸, 원숭이, 개미핥기, 레서팬더, 악어 | 걷거나 방향을 틀며 이동. 꽃, 풀빛 지형, 미세한 흔들림 |
| 수족관 | 옆에서 본 바닷속 | 가오리, 크라운피시, 개복치, 고래상어, 해룡 | 좌우로 헤엄치며 부드럽게 위아래로 뜸. 기포, 수초, 빛줄기 |
| 하늘 | 옆에서 본 하늘 | 관학, 독수리, 갈매기, 큰부리새, 빨간 마코앵무 | 이동 방향을 바라보며 날아다님. 천천히 움직이는 구름 |
| 숫자 나라 | 파스텔 놀이판 | 0~9 중 매 라운드 무작위 5종 | 숫자는 똑바로 유지한 채 이동. 색종이 장식 |

동물은 테마에 맞는 시점으로 그린다. 색과 실루엣만 봐도 종을 구별할 수 있게 하고, 작은 크기에서도 눈·무늬 등 특징이 남도록 한다. 배경 장식은 판정을 방해하지 않게 동물보다 낮은 대비로 둔다.

## 4. 핵심 규칙과 관대한 판정

1. 각 손가락의 선을 독립적으로 기록한다. 선이 직접 지나간 대상이 같은 종류 2개 이상뿐이면 열린 선으로도 합친다. 다른 종류가 닿은 열린 선은 실패한다.
2. 둘러 그린 선은 시작점과 끝점을 자동으로 이어 영역을 만든다. 영역에 **같은 종류 2개 이상**이 선택되면 크기가 달라도 모두 하나로 합친다. 3개 이상도 한 번에 합칠 수 있다.
3. 같은 종류는 몸이 영역에 조금만 걸쳐도 선택한다. 현재 기준은 몸 면적의 약 **3% 이상**이다.
4. 다른 종류는 몸 면적의 **50% 이상**이 영역에 들어왔을 때만 합치기를 방해한다. 경계에 조금 닿은 다른 대상 때문에 어린이가 실패하지 않도록 하기 위한 규칙이다.
5. 다른 종류가 방해하거나 같은 종류를 2개 이상 잡지 못하면 점수를 주지 않고 짧은 안내를 띄운다. 감점은 없다.
6. 두 사람이 동시에 같은 대상을 둘러도 먼저 완료된 합치기부터 처리한다. 이미 합쳐진 대상은 다음 판정에서 사라지므로 점수가 중복되지 않는다.

선 판정은 표시 크기에 비례한 원판과 선분의 거리를 사용한다. 영역 판정은 원판을 여러 지점에서 샘플링해 계산한다. 어린이용 조작을 위해 정교하게 원을 닫을 필요는 없다. 너무 짧은 낙서만 무시한다.

## 5. 성장과 점수

| 같은 단계 한 쌍 | 합치기 후 | 점수 |
| --- | --- | ---: |
| 1단계 | 2단계 | 60 |
| 2단계 | 3단계 | 150 |
| 3단계 | 4단계 | 360 |
| 4단계 | 5단계 | 800 |
| 5단계 | 6단계 | 1,700 |
| 6단계 | 6단계 유지 | 3,400 |

성장은 6단계에서 멈춘다. 크기가 다른 대상도 합칠 수 있고, `가장 큰 단계 + ⌊log₂(선택한 개수)⌋`만큼 성장한다. 예를 들어 1단계 네 개는 3단계 한 개가 된다. 점수는 가장 큰 대상을 제외한 나머지의 단계별 기본 점수 합계에 성장 보너스를 더한다. 성장 보너스는 `도달한 단계 직전의 기본 점수 × (합친 개수 - 1)`이다. 6단계끼리 합치면 성장 대신 같은 단계의 보너스를 준다. **3단계 한 쌍의 360점은 1단계 세 쌍의 180점보다 2배 높다.** 실제 플레이에서 평균 점수와 성공 횟수를 보고 조정한다.

기본 동물 크기는 화면의 짧은 변에 따라 44~90px이며 단계마다 기본 크기의 약 35%씩 커진다. 최대 크기는 화면의 짧은 변의 36% 또는 230px으로 제한한다. 합치기 직후에는 목표 크기를 잠시 넘었다가 작게 흔들리며 안정되는 젤리 동작을 보여준다.

## 6. 난이도·등장량

- 시작할 때 종류별 3~6개를 화면 전체에 섞어서 배치한다. 같은 종류가 뭉쳐 시작하지 않도록 위치를 벌린다.
- 작은 화면에서는 약 15마리, 일반 화면에서는 약 20마리, 와이드 화면에서는 약 30마리를 유지한다. 안전 상한은 각각 19마리·27마리·36마리다.
- 합쳐서 수가 줄면 1단계 대상을 보충한다. 새 대상은 빈 공간에 나타나며 같은 종류 옆에 의도적으로 놓지 않는다.
- 이동 속도는 동물마다 시작할 때 다르게 정한다. 작은 화면은 초당 약 75~120px, 큰 화면은 약 95~150px에서 단계 크기에 따라 조절한다. 벽에 닿으면 방향을 반사하고 속도를 다시 뽑는다. 이동 중 방향은 부드럽게 조금씩 바뀐다.
- 목표 플레이 감각: 동물들이 활발히 이동하지만 어린이가 조작을 이해한 뒤 **첫 10초 안에 한 번 이상 성공**하고, 실패하더라도 곧 다시 시도할 수 있다.

이 수치는 첫 플레이 테스트를 위한 가설이다. 성공률이 낮으면 등장 위치와 속도를 먼저 조정하고, 점수는 그다음 조정한다.

## 7. 화면·소리 방향

- 로비: 이미지 카드가 가장 큰 클릭 영역이 된다. 한 문장으로 조작을 설명한다.
- 플레이: 화면 전체를 게임판으로 쓰고, 점수·원형 타이머·최고 점수를 투명한 글자 HUD로 위에 얹는다. HUD와 마지막 5초의 반투명 노란 카운트다운은 터치 입력을 통과시킨다. 글자에는 가독성을 위한 그림자만 두고 카드 배경은 없다. 아이폰 가로 화면에서는 로비, 플레이, 결과를 스크롤 없이 볼 수 있도록 압축한다.
- 결과: 점수와 축하 연출을 먼저 보여주고, 등수와 재시작 버튼을 바로 아래에 둔다.
- UI: 부드러운 원형, 파스텔 색, 큰 글자와 버튼을 사용한다. 같은 정보를 색에만 의존해 전달하지 않는다.
- 소리: 쉼표가 있는 경쾌한 배경 멜로디를 낮은 볼륨으로 재생한다. 합치기 성공음은 짧은 팝 소리와 상승하는 음을 섞고 높은 단계에서 조금 풍성하게 한다. 소리 끄기 상태를 저장한다.
- 움직임 감소 설정을 존중한다. 터치 중 브라우저 스크롤이나 확대가 게임 입력을 방해하지 않게 한다.

## 8. 기록·기술 설계

- **클라이언트:** TypeScript와 Three.js. Three.js가 동물 스프라이트와 환경 장식을 렌더링하고, HTML/CSS가 로비·HUD·결과 UI를 맡는다.
- **멀티터치:** Pointer Events의 `pointerId`별로 선을 관리한다. 모든 사람은 한 라운드의 공동 점수를 올린다.
- **기록:** 현재 버전은 테마별 점수와 등수를 같은 기기의 `localStorage`에 저장한다. 기기 간 공통 순위가 필요하면 서버 저장소·사용자 식별·비정상 점수 방지 규칙을 별도로 설계한다.
- **PWA:** 설치 가능한 매니페스트와 서비스 워커로 앱 자산을 캐시한다. 첫 방문에는 네트워크가 필요하고, 캐시된 뒤에는 오프라인 재실행이 가능해야 한다.
- **성능:** 휴대전화와 태블릿에서 동물 이동과 선 그리기가 끊기지 않도록 동물 수와 픽셀 비율을 제한한다.

## 9. 제작 순서와 완료 기준

| 단계 | 산출물 | 완료 기준 |
| --- | --- | --- |
| 1. 플레이 가능한 원형 | 네 테마, 90초 타이머, 유닛 이동, 선 잇기·원 그리기, 합치기 | 각 테마에서 실제 터치로 점수가 오름 |
| 2. 어린이용 연출 | 카드 로비, 동물 아트, 배경, 소리, 성공 효과, 결과 화면 | 게임 방법과 다음 행동을 설명 없이 찾을 수 있음 |
| 3. 기록·설치 | 최고 점수, 등수, PWA | 결과를 다시 열어도 기록 유지, 앱 자산 캐시 확인 |
| 4. 플레이 테스트 | 어린이·보호자 관찰, 수치 조정 | 첫 성공 시간·실패 이유·평균 점수·재도전율 확인 후 난이도 조정 |

현재 저장소에는 **1~3단계의 첫 구현**이 있다. 화면과 기본 규칙은 동작하며, 4단계의 실제 사용자 테스트와 밸런스 조정은 아직 진행하지 않았다. 기기 간 공통 순위가 필요한지도 출시 범위를 정할 때 확정해야 한다.
